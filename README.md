# Eivor Labs account: UI demo

A static, sample-data-only demo of the redesigned owner account (sign-in, Today, Calls, Calendar, Robot, Settings, Ctrl/Cmd K quick jump).

**Live:** https://adithyaparthasarathy.github.io/eivor-account-demo/

Sign in with `owner@example.com` / `sample-password`, then choose any new password of 10+ characters. Everything is made-up sample data kept in memory only; nothing is sent anywhere.

No build step: plain HTML, CSS and ES modules, with GSAP, SplitText and Lenis vendored in `assets/vendor` (licences in `assets/vendor/LICENSES.md`).
